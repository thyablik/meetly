# Meetly — видеовстречи без регистрации

Мини-проект на HTML, CSS, JavaScript и PeerJS.

## Запуск
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Запустите `index.html` через расширение **Live Server** (или любой локальный HTTP-сервер).
4. Разрешите браузеру доступ к камере и микрофону.
5. Создайте комнату и отправьте ссылку/код другому участнику.

Для доступа по ссылке с другого устройства страница должна быть опубликована на HTTPS-хостинге (например, GitHub Pages, Netlify или собственном сервере).

## Возможности
- Комнаты по коду без аккаунтов
- Видео и аудио через WebRTC
- Выключение микрофона и камеры
- Демонстрация экрана
- Чат и быстрые реакции
- Адаптивный интерфейс и переключение темы

## Важно: ограничения прототипа
- PeerJS использует публичный PeerServer для обмена служебными данными, а медиа передаётся напрямую между браузерами (P2P).
- Это mesh-прототип для небольших комнат: каждый участник соединяется с остальными, поэтому нагрузка быстро растёт с количеством людей. Для большой конференции нужен SFU-сервер (например, mediasoup или LiveKit).
- Для сложных сетей может понадобиться TURN-сервер. Без него часть соединений не установится.
- В текущем прототипе комнаты не защищены паролем, а имя участника не является подтверждённой личностью.
- Владелец комнаты должен оставаться подключённым; если он закроет вкладку, комната перестанет принимать новых участников.
- Публичный PeerServer и CDN — внешние зависимости, их доступность не гарантируется.

Это стартовый прототип, не замена Google Meet для важных или конфиденциальных встреч.
